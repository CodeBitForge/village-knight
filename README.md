# village-knight
A 2D pixel-art story-driven game about a village boy entering a knights tournament


**عنوان فارسی:** شوالیه‌ی روستا  
**وضعیت:** در حال توسعه (فاز سناریو و پیش‌تولید)

بازی ۲ بعدی پیکسل‌آرت با تمرکز بر داستان، رشد شخصیت و انتخاب‌های اخلاقی.  
بازیکن در نقش لئون، پسر روستایی قرار می‌گیرد که برای کمک به خانواده‌اش در یک مسابقه‌ی بزرگ شوالیه‌ها شرکت می‌کند.

---

## درباره‌ی پروژه

این ریپازیتوری مربوط به پروژه‌ی درس بازی‌سازی است.

- **موتور بازی:** Godot 4
- **سبک هنری:** Pixel Art (۲D)
- **پلتفرم هدف بتا:** Windows
- **پلتفرم هدف نهایی:** Android (Google Play)
